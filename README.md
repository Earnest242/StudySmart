# StudySmart -- > icllass
- N/B app initially named studysmart but renamed to icllass
- It's a react native app that simplifies how students can access and share class materials such as notes, timetables and assignment info.
- works almost like google drive shared files architecture but particularly tailored for students and allows limited write rights in a particular classroom.
- Working on implemting a chat feature to it.
